Start a session

  1. The DM runs START_LOCAL_SERVER.bat on a Windows computer and opens this page at http://localhost:8765.
  2. The DM opens a phase, clicks Multiplayer, enters a name, and selects Host as DM.
  3. Players on the same network open http://DM-COMPUTER-IP:8765, choose a phase and enter the DM's six-character session code.
  4. Players select Join as Player. Keep the server window running during play.

Important: Opening pages directly as a file or through dndpov.com bypasses the local multiplayer server. Use the :8765 address for every player.
